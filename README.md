# Boom

<img src="boom-1024.png" width="128" alt="Boom icon">

When you close a window, it explodes into tiny particles that drift upward and fade away.

<video src="web/boom.mp4" width="800" autoplay loop muted playsinline></video>

Requires macOS 15 (Sequoia) or later.

## Install

1. Download [Boom.zip](https://github.com/vladstudio/boom/releases/latest/download/Boom.zip)
2. Unzip and drag `Boom.app` to `/Applications`
